# دفتر البيع والديون

تطبيق جوال عربي بسيط لتسجيل العملاء والمبيعات والديون والدفعات الجزئية. يعمل دون اتصال بالإنترنت ويحفظ البيانات محليًا على الجهاز باستخدام SQLite.

## التشغيل

1. ثبّت Node.js وExpo Go على هاتفك.
2. من مجلد المشروع شغّل `npm install`.
3. شغّل `npx expo start`.
4. امسح رمز QR باستخدام Expo Go، أو استخدم `npm run android` لمحاكي Android و`npm run ios` لمحاكي iOS على macOS.

## المزايا الحالية

- لوحة ملخص لمبيعات اليوم، وإجمالي المبيعات، والديون المتبقية، وعدد العملاء.
- إضافة العملاء مع رقم الهاتف.
- تسجيل المبيعات النقدية والآجلة؛ البيع الآجل ينشئ دينًا تلقائيًا.
- تسجيل دين مستقل للعميل.
- تسجيل دفعة كاملة أو جزئية مع تحديث الرصيد المتبقي.
- واجهة عربية واتجاه من اليمين إلى اليسار، مع تخزين محلي دون الحاجة إلى حساب أو اتصال.

## ملاحظة

البيانات مخزنة على الجهاز الحالي فقط. احفظ نسخة احتياطية قبل حذف التطبيق أو مسح بياناته. العملة غير مثبتة في التطبيق؛ الأرقام تعرض كمبالغ مجردة.
