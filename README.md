# دفتر البيع والديون

تطبيق جوال عربي لتسجيل العملاء والمبيعات والديون والدفعات الجزئية. يعمل دون اتصال بالإنترنت ويحفظ البيانات محليًا على الجهاز باستخدام SQLite.

## تشغيل التطبيق للتطوير

1. ثبّت Node.js وExpo Go على هاتفك.
2. شغّل `npm install`.
3. شغّل `npx expo start`.
4. امسح رمز QR باستخدام Expo Go.

## بناء ملف APK للأندرويد

يستخدم المشروع EAS Build لإنشاء APK سحابيًا:

1. ثبّت Node.js، ثم من مجلد المشروع شغّل `npm install`.
2. سجّل الدخول إلى حساب Expo: `npx eas-cli login` (أنشئ حسابًا مجانيًا إذا لم يكن لديك حساب).
3. اربط المشروع بحسابك عند أول استخدام: `npx eas-cli build:configure`.
4. ابدأ إنشاء APK: `npm run build:apk`.
5. عند اكتمال البناء، افتح رابط البناء الذي يعرضه EAS أو صفحة المشروع في Expo، ثم نزّل ملف APK وثبّته على جهاز Android.

ملف `eas.json` يضبط ملف APK في ملف البناء `preview`. لبناء إصدار متجر Google Play بصيغة AAB استخدم: `npx eas-cli build --platform android --profile production`.

> يتطلب إنشاء الملف اتصالًا بالإنترنت وحساب Expo. لم يتم تضمين ملف APK جاهز في المستودع؛ يُنتَج عبر خدمة EAS بعد تنفيذ أمر البناء.

## المزايا الحالية

- ملخص مبيعات اليوم، وإجمالي المبيعات، والديون المتبقية، وعدد العملاء.
- إضافة العملاء مع رقم الهاتف.
- تسجيل المبيعات النقدية والآجلة؛ البيع الآجل ينشئ دينًا تلقائيًا.
- تسجيل دين مستقل للعميل.
- تسجيل دفعة كاملة أو جزئية مع تحديث الرصيد المتبقي.
- واجهة عربية واتجاه من اليمين إلى اليسار، مع تخزين محلي دون الحاجة إلى اتصال.

## ملاحظة

البيانات مخزنة على الجهاز الحالي فقط. احفظ نسخة احتياطية قبل حذف التطبيق أو مسح بياناته. العملة غير مثبتة في التطبيق؛ الأرقام تعرض كمبالغ مجردة.
